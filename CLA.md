terms the Owner chooses, including licences that differ from the Project's

## 7. Signing

Sign by opening a pull request that adds one entry to `cla/signatures.json` and
changes nothing else:

```json
{ "github": "your-github-login", "name": "Your Full Legal Name", "date": "YYYY-MM-DD" }
```

Opening that pull request is your agreement to these terms. Signing once in a
repository covers all your later contributions to that repository.

The automated check on every pull request confirms the author appears in that
file. A pull request that touches only `cla/signatures.json` is allowed through
the check — otherwise signing would require having already signed.
